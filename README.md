# care_planning_data
The home of a repository of code and data scraping planning permissions of care homes. For now this is a proof of concept. If funding is secured, I hope to make this a national resource to identify the locations and successes of care planning permissions.


## What is made available?
The basic files available to use are:
 - Final cleaned datasets (in data folder)
 - Code to scrape care homes in Oxfordshire (in code folder)
